# Portfólio Augusto Amado

Portfólio pessoal construído com React e Vite para apresentar projetos, experiência profissional e stack técnica.

## Stack

- React 19
- Vite
- Tailwind CSS
- React Router
- Radix UI

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/pages`: páginas principais e páginas de projeto
- `src/data`: conteúdo estruturado do portfólio
- `src/components`: componentes reutilizáveis de layout e UI
- `public`: assets públicos, incluindo avatar, banners e currículo
